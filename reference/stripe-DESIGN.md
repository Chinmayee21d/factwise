## Overview

Professional, trustworthy, and modern with a clean aesthetic that conveys reliability and sophistication. The design feels spacious yet efficient, with a medium density that balances information hierarchy with visual breathing room.

Consistent grid system with 8px base spacing unit. Content is contained within max-width containers, with generous section spacing (24px, 32px, 64px) creating clear visual separation. Navigation uses fixed outer padding of 8px with 16px inline spacing.

Uses a 4px base grid with scale: 0.5, 1, 2, 4, 6, 8, 16.

## Colors
- **Stripe Purple** (#533afd): Primary buttons, links, and brand elements
- **Deep Navy** (#061b31): Primary headings and high-emphasis text
- **Text Secondary** (#50617a): Secondary text and descriptions
- **Text Subdued** (#64748d): Subdued headings and less prominent text
- **Background Primary** (#ffffff): Main background and card surfaces
- **Cloud White** (#f8fafd): Subtle background areas and sections
- **Background Neutral** (#e5edf5): Neutral background elements
- **Accent Orange** (#ff6118): Accent elements and highlights
- **Border Default** (#d4dee9): Default borders and dividers

## Typography
- **Headline Font**: sohne-var
- **Body Font**: sohne-var
- **Label Font**: sohne-var

The typography system relies exclusively on the custom Sohne variable font, creating a cohesive and distinctive brand voice. Weight conventions use 300 for headings and 400 for body text, with occasional 300 weight for secondary body content. Size relationships follow a clear hierarchy from 26px headings down to 10px labels, with negative letter-spacing (-0.26px) applied to larger headings for optical balance. Line-height varies contextually, with tighter leading for headings (1.12x) and more generous spacing for body text (1.4x).

## Elevation

Subtle depth strategy using soft shadows with low opacity (rgba values around 0.08-0.12) and multiple shadow layers. Cards and modals use gentle elevation without harsh contrasts, maintaining the clean aesthetic while providing clear visual hierarchy.

## Components
- **Primary Button**: Purple background (#533afd) with white text, 6px border radius
- **Secondary Button**: Outlined button with purple border and purple text
- **Card Component**: White background with subtle shadows and rounded corners
- **Navigation Header**: Clean horizontal navigation with consistent spacing and typography
- **Feature List**: Bulleted list with orange accent markers and consistent spacing
- **Modal Dialog**: Centered modal with close button and structured content layout

## Do's and Don'ts
- Do use the 8px spacing base unit for consistent rhythm throughout layouts
- Don't use border radius values outside the established 2px, 4px, 6px, 8px, 16px scale
- Do maintain the purple brand color (#533afd) for all primary actions and brand elements
- Don't use pure black (#000000) for text; prefer the softer navy (#061b31) for better readability
- Do use the Sohne variable font consistently across all text elements
- Don't exceed 300 font weight for headings to maintain the light, modern aesthetic
- Do use orange (#ff6118) sparingly as an accent color for highlights and emphasis
- Don't create harsh shadows; keep shadow opacity low (0.08-0.12) with blue-tinted colors
